# 智在记录 Skill

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

让 AI 连接你的智在记录。随时记录，需要时召回与总结。

---

## ✨ 核心能力

| 能力 | 说明 |
|------|------|
| **⚡ 场景落地** | 按用户场景组合执行：做成笔记（自动判断类型、默认等待）、名称先查 ID、创建成功 ≠ 转写完成 |
| **📒 笔记 CRUD** | 列表/详情/做成笔记/修改/删除/等待处理完成；录音/文档/图片可入库 |
| **🎬 场景与知识卡** | 我的场景、内置场景、知识卡；保存前按名称解析 `sceneId` |
| **📚 笔记集** | 按名称打开我创建的/我收到的笔记集；可新建、建目录、移笔记、归档 |
| **🔎 问小智** | 先创建会话再 SSE 语义问答；可限定笔记/笔记集/目录 |
| **📝 动态模版问答** | 写周报/复盘时先查标准输出模版，再填真实笔记；不是问小智 |
| **🔑 开放平台鉴权** | 使用开发者 API Key 连接；探活用笔记列表 |

本 Skill **不做**团队管理、发消息、录音卡用量查询，也不能把视频做成笔记。

## 📦 安装

### 方式一：把一句话发给 AI（推荐）

把这句话发给 WorkBuddy、Claude、Codex 等 AI：

> 请从 https://github.com/BoteAI/zhizai-openclaw 安装智在记录 Skill，并引导我完成授权。

### 方式二：下载 Skill 安装包

打开 [智在记录 Skill 发布页](https://github.com/BoteAI/zhizai-openclaw/releases/latest)，下载最新版 ZIP，拖进 AI 的聊天框，然后说：

> 请安装这个智在记录 Skill，并引导我完成授权。

本地从源码打包：

```bash
python scripts/build_skill_package.py
# 产出 dist/zhizai-openclaw-1.0.2.zip
```

## 🔑 授权登录

首次使用时，AI 会引导你到智在记录开发者平台获取 API Key，再完成本地配置。

获取 Key：https://www.zzjilu.com/pc/developer

安装完成后，AI 会依次确认：

1. 已配置 `ZHIZAI_REC_API_KEY`；
2. 可以读取当前账号的笔记列表；
3. 当前 AI 已加载笔记、场景、笔记集与问小智能力。

默认先读取最近笔记做无写入验收，不会擅自创建测试内容。Skill 本身不会执行下载脚本或自行覆盖文件。

鉴权 Header：`Authorization: <api-key>`（**不要**加 Bearer）。  
开放 API：`https://openapi.zzjilu.com/api/v1`

## 🛠 支持的笔记类型

| 类型 | 说明 | 支持 |
|------|------|------|
| `text` | 文本笔记 | ✅ 读写 |
| `link` | 链接笔记 | ✅ 读写 |
| `image` | 图片笔记 | ✅ 读写 |
| `document` | 文档笔记 | ✅ 读写 |
| `voice` | 录音笔记 | ✅ 读写（含转写与进度） |
| `video` | 视频笔记 | 📖 已有可查；不能做成笔记 |
| `knowCard` | 知识卡片 | 📖 读取 / 场景侧管理 |

创建与文件依赖：

- 「做成笔记」时按文件扩展名自动判断类型，不必追问录音还是文档；对外一次完成，内部才上传+创建+等待；
- 录音/文档/图片默认等到处理完成（用户明确说不用等除外）；创建成功 ≠ 转写/总结完成；
- 「找、搜、关于某主题」走问小智（先会话再 SSE），不会用标题过滤冒充语义搜索；
- 用户要按结构成文（周报、复盘）时走动态模版管线。

## 💡 使用场景与进阶用法

### ✏️ 随手记录

**通勤路上想到一个点子**

> 👤 记一下笔记：支付流程可以加一个进度条，用户等待时不焦虑
>
> 🤖 已记录为文本笔记。

**开完会**

> 👤 帮我记下刚才会上定的几件事：1. 下周三前完成设计稿 2. 找小王对接接口 3. 周五前给老板汇报进度
>
> 🤖 已记录。

### 🔍 要用时召回与总结

**被领导问到**

> 👤 上次报销相关的讨论记在哪了？
>
> 🤖 找到 3 条相关笔记，最近一条是……

### 📚 整理到笔记集

你可以直接对 AI 说：

> 看看我创建的笔记集，把刚才那条放进「产品研究」。

AI 会先读取真实笔记集，再执行操作，不会根据名称猜 ID。

AI 会从 [GitHub 仓库](https://github.com/BoteAI/zhizai-openclaw) 拉取最新 Skill，再做无写入验收。需要平台确认时只提示必要动作。

## 🔐 安全说明

> ⚠️ **隐私保护**：笔记是你的私密数据，AI 会严格校验身份。

- 默认只访问当前 API Key 对应账号的数据；
- 删除、覆盖前会先确认；
- 不会要求你在聊天中发送完整 API Key 或 Authorization；
- 失败会说明真实原因和下一步，不展示服务端 `stack`。
